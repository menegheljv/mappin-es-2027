## Arquivos

- [`index.html`](./index.html): página inicial com links pra tudo
- [`deck.html`](./deck.html): pitch deck completo (8 slides, 1920×1080)
- [`identidade-visual.html`](./identidade-visual.html): paleta, tipografia e regras de uso da raposa
- [`mapa-territorio.html`](./mapa-territorio.html): mapa do ES, Grande Vitória x interior
- [`divisao-tarefas.html`](./divisao-tarefas.html): slide vertical (1080×1920) com a divisão de tarefas do grupo
- [`CONTEUDO.md`](./CONTEUDO.md): texto de todos os slides, separado do design
- `fox-red.png` / `fox-cream.png` / `fox-orange.png`: logo da raposa, nas variações de cor

Abra os `.html` direto no navegador pra visualizar ou apresentar.
